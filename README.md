# 💬 Real-Time Chat

A real-time chat web application built with vanilla JavaScript, HTML, and CSS. Deployed on GitHub Pages.

## Overview

This project implements a real-time chat interface in the browser. Users can send and receive messages in a live chat experience, built without any backend framework using client-side JavaScript.

## Features

- Real-time messaging interface
- Clean chat UI
- Responsive design
- Deployed on GitHub Pages

## Tech Stack

| Component | Technology |
|-----------|------------|
| Markup    | HTML       |
| Styling   | CSS        |
| Logic     | JavaScript |
| Hosting   | GitHub Pages |

## Getting Started

Open `index.html` in a browser to run locally.
